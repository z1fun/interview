## ⚡ 快速参考卡

### 必须记住的核心术语
| 术语 | 一句话解释 |
|------|-----------|
| 幂等性 | 同一操作执行多次结果相同，支付场景防重复扣款 |
| 最终一致性 | 数据短暂不一致但最终会一致，BASE理论核心 |
| CAP定理 | 一致性/可用性/分区容错，最多同时满足两个 |
| GMP模型 | Go调度器：G(goroutine) + M(系统线程) + P(逻辑处理器) |
| 熔断 | 下游服务故障时快速失败，防止级联故障 |
| RED方法 | Rate/Errors/Duration，服务监控三指标 |
| OpenTelemetry | 统一可观测性数据采集标准（Traces+Metrics+Logs） |
