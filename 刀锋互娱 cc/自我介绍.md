# 自我介绍｜约 45—60 秒

您好，我有五年左右后端开发经验，主要用 Go，也做过 Python 的 AI 应用和 Vue 全栈。

最近一年多我在诚迈科技做 AI 应用后端。在 AI 数字人项目里，我负责后端对话流程，包括意图识别、场景路由和结构化回复，并搭建了分层记忆系统，把近期对话、会话摘要、长期摘要和稳定事实组织起来支撑跨会话上下文；同时对接腾讯 IM 消息并做了幂等处理，接入 Gemini Live 实时语音，负责金币计费和跨实例通话控制。另一个 AI 漏洞研判系统里，我用 LangGraph 搭了多 Agent 工作流，用 FastAPI + PostgreSQL + pgvector 做 RAG 知识库，并接入飞书卡片做人工审批。

再早一些在思迅软件，我用 go-zero + gRPC + RabbitMQ 做 POS 数据中台，统一接入多产品线的销售流水、商品档案和电子发票数据，对微服务和消息队列比较熟悉。

这次岗位是 Golang 后端 Agent 方向，我做过的 Agent 对话、记忆系统和实时通信跟岗位要求比较匹配，希望能进一步交流。

## 两个可能的追问

**语音是怎么接的？** 后端负责 Gemini Live 的会话生命周期、跨实例通话控制和金币计费；音频编解码、打断检测由模型和客户端 SDK 处理。讲清楚自己负责的边界，不夸大音频技术细节。

**记忆系统规模多大？** 按真实情况讲角色数、记忆层如何检索组装，不编造数据量；被追问细节时用“分层 + 异步摘要 + 按相关性注入”的结构回答。

练习两遍即可。只讲真实职责，不补造数据量、性能提升或技术使用经历。
