# Agent 工程化｜60 分钟

用时：流式与工具调用 25 分钟，上下文与记忆 25 分钟，成本 10 分钟。岗位核心方向，结合 LoveSpouse 数字人与漏洞研判两个真实项目讲。

## 1. 模型接入与编排

- **直连 vs 网关**：直连简单；业务量大后走网关做统一鉴权、限流、配额、成本统计、模型路由与降级切换。
- **模型分级**：小模型做意图识别/情绪分类/审核，大模型做生成——省钱、降延迟。数字人的意图识别 + 场景路由正是这个思路。
- **关键参数**：`temperature` 低→稳定可复现，高→发散（创意场景）；`max_tokens` 限制输出长度与成本；`stop` 提前终止。
- **编排框架**：LangGraph 用图（节点 + 边）+ 共享状态 + 人工介入点组织多步流程。漏洞研判的真实流程：信息完整性评估 → POC 验证 → 定级定价 → 复测，中途飞书卡片人工审批。
- **何时编排**：多步骤、有分支、需要工具/人工介入时；单轮问答一个 Prompt 足够。

## 2. 流式输出

- **SSE**：单向文本流，格式为 `data: ...` 行；可发注释行（`:` 开头）做心跳。客户端逐 chunk 渲染，体验好于等整段。
- **选型**：纯文本流用 SSE 简单够用；**双向实时交互（语音）用 WebSocket**（Gemini Live 即 WS 双向流）。
- **Nginx 等代理会缓冲**：加 `X-Accel-Buffering: no`，否则流式退化成一次性返回。
- **断流处理**：超时/异常中断时客户端提示重试或降级为非流式；服务端流结束要发结束标记。
- **指标分开看**：TTFT（首 token 延迟）、生成速率、整段时长，优化目标不同。

## 3. 工具调用（function calling）

一个回合：模型输出结构化调用（工具名 + JSON 参数）→ 服务端执行 → 结果作为新消息回填 → 模型继续生成或再调用。

服务端必须做：

1. **白名单校验**：只执行允许的工具，参数按 schema 校验。
2. **超时与失败回传**：工具报错作为结果回传，让模型换方式重试，而不是直接报错给用户。
3. **轮数上限**：限制单轮最大工具调用次数，防循环烧 token。
4. **危险操作**：写操作/支付类要求人工确认（漏洞研判的飞书审批就是人工介入的例子）。

## 4. 上下文管理

上下文窗口有限、按 token 计费，不能无限堆积历史。常用组合：

- **滑动窗口**：只保留最近 N 轮原文。
- **摘要**：超出窗口的对话压缩成摘要顶替原文。
- **稳定事实**：用户档案类信息独立存储，按需注入。
- **结构化输出**：让模型返回 JSON，业务层校验、加工后再展示（数字人结构化回复 + 付费互动推荐的做法），避免把模型文本直接当业务数据。

## 5. 分层记忆（LoveSpouse 真实经验）

四层组织：

| 层 | 内容 | 特点 |
|---|---|---|
| 近期对话 | 最近轮次原文 | 保留细节，占用最多 |
| 会话摘要 | 本次会话压缩 | 会话结束后异步生成 |
| 长期摘要 | 跨会话的历史压缩 | 支撑长期陪伴感 |
| 稳定事实 | 用户档案、偏好 | 独立维护，可更新删除 |

- 摘要生成放会话结束后异步做，不阻塞回复；组装 prompt 时按相关性选取记忆层。
- **边界**：摘要必然丢失细节；稳定事实要能纠正（用户说错了要更新）；记忆涉及隐私，注意存储与合规。

## 6. RAG

流程：文档切分 → 向量化 → 存入向量索引（pgvector）→ 检索 top-k → 拼入 prompt 生成。

- **防幻觉**：检索结果相似度过低或为空时，明确告诉模型“没有找到依据”，而不是自由发挥。
- **pgvector**：PostgreSQL 扩展，向量与业务数据同库，简化运维——漏洞研判知识库的真实做法。
- 检索质量靠 top-k、阈值、重排调优；先保证召回再谈生成。

## 7. 成本与延迟优化

1. **模型分级**：意图/分类用小模型，生成才用大模型。
2. **压缩输入**：摘要顶替原文，砍 token。
3. **缓存**：相同意图、固定内容的结果缓存；Prompt 模板化。
4. **异步化**：摘要、入库等非用户链路任务异步处理。
5. **计量对齐**：按 token 用量做成本统计；业务计费（数字人金币计费）与模型成本对齐，余额不足要能中断服务。

## 8. Prompt 基础

- 结构：角色 + 任务 + 输入 + 输出格式（JSON schema/枚举）+ few-shot 示例。
- 迭代要有评测集：同一批用例对比调整前后效果，不靠感觉。
