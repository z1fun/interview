# Golang 后端工程师（Agent 方向）

| 项目 | 信息 |
| --- | --- |
| 薪资 | 15–25K |
| 工作地点 | 深圳 |
| 经验要求 | 不限 |
| 学历要求 | 本科 |

## 岗位职责

1. 负责 C2C 陪玩社交 AI 产品的后端研发，支撑 Agent 实时交互、高并发访问及稳定运行。
2. 负责 Agent 服务、会话管理、任务调度、模型接入及业务 API 等模块的设计与实现。
3. 参与 LLM / Agent 工程化落地，包括模型编排、流式输出、工具调用、上下文管理和记忆能力等。
4. 优化系统性能、响应延迟、资源使用及模型调用成本，提升产品整体体验。
5. 完善服务监控、日志、压测、容灾和故障排查机制，保障线上系统稳定性。
6. 与产品、算法、客户端、测试团队协作，快速响应业务需求并持续迭代。

## 任职要求

1. 具备扎实的 Golang 开发能力和良好的工程习惯，有独立负责服务或核心模块的经验。
2. 熟悉并发编程、网络通信、微服务、RPC、消息队列、缓存、数据库等后端技术。
3. 具备高并发、低延迟、实时通信或分布式系统开发经验。
4. 对大模型、AI Agent 及相关工程技术有兴趣，愿意深入理解业务场景并快速学习。
5. 具备较强的落地能力、自驱力和问题解决能力，能够推动功能从开发到上线。
6. 具备良好的代码质量意识、测试意识和团队协作能力。
