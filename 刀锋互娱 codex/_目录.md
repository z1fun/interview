# Golang 后端工程师（Agent 方向）面试知识目录

> 岗位：刀锋互娱 · C2C 陪玩社交 AI 产品
>
> 优先级：P0 为必须能够结合项目清晰讲述，P1 为高频追问项，P2 为加分项。

## 1. 个人项目与岗位匹配（P0）

1. **LoveSpouse 数字人：端到端链路**
   - 一次文本/语音请求从 IM、网关、会话服务、Agent 到流式响应的时序。
   - 意图识别、场景路由、付费互动推荐和结构化回复的职责边界。
   - Gemini Live 实时语音接入、跨实例通话控制、计费与异常处理。
2. **会话与记忆系统**
   - 近期对话、会话摘要、长期摘要、稳定事实的分层与读写时机。
   - 上下文选择、Token 预算、记忆冲突与过期处理。
   - 个性化与用户隐私边界。
3. **AI 漏洞研判系统：Agent 工作流**
   - LangGraph 多 Agent 节点、状态传递、条件分支与人工审批。
   - RAG 检索、pgvector、Prompt 设计及可观测性。

## 2. Go 服务端基础与并发（P0）

1. goroutine、channel、context 的使用边界与取消传播。
2. `sync.Mutex`、`RWMutex`、`WaitGroup`、`Once`、`Map` 的适用场景。
3. goroutine 泄漏、数据竞争、死锁的定位和预防；race detector。
4. worker pool、限流、背压、超时与熔断在模型调用中的应用。
5. GC、逃逸分析、pprof 的基本使用与性能优化思路。

## 3. 实时通信与流式输出（P0）

1. WebSocket 生命周期：鉴权、心跳、断线重连、消息顺序、幂等。
2. SSE 与 WebSocket 的区别，以及 Agent token 流式输出的选型。
3. IM 回调的重复投递、乱序、重试和消息去重。
4. 长连接的连接管理、水平扩展与跨节点路由。

## 4. LLM / Agent 工程化（P0）

1. 模型调用契约：超时、重试、退避、降级、结构化输出校验。
2. Tool Calling：工具 schema、权限、参数校验、幂等与审计。
3. Prompt 注入防护、内容安全、敏感信息脱敏。
4. 评估体系：成功率、延迟、Token、工具错误率、人工满意度。
5. 成本优化：上下文压缩、缓存、路由、模型分级与并发控制。

## 5. 分布式服务与数据层（P1）

1. gRPC / Protobuf：接口演进、deadline、重试、错误码、拦截器。
2. Redis：缓存穿透/击穿/雪崩、分布式锁、会话状态与限流。
3. MySQL：索引、事务隔离、慢查询、分页、幂等表设计。
4. RabbitMQ：确认机制、重复消费、死信队列、顺序与消息积压。
5. ETCD 服务发现与配置管理；最终一致性与 Outbox 思路。

## 6. 高并发、低延迟与稳定性（P1）

1. 容量评估：QPS、并发连接、平均/尾延迟、模型并发配额。
2. 压测方案、瓶颈定位与逐层优化。
3. 监控告警：Metrics、日志、Trace 的关联；核心 SLI/SLO。
4. 灰度、回滚、限流、熔断、降级、容灾与故障复盘。

## 7. 社交陪玩 AI 业务理解（P1）

1. 实时性、角色一致性、情感陪伴与付费转化的技术取舍。
2. 用户未成年人保护、内容审核、隐私与数据留存策略。
3. 付费权益、计费幂等、风控和异常补偿。
4. 从 MVP 到规模化的服务拆分与迭代优先级。

## 8. 协作与行为面试（P1）

1. 跨产品、算法、客户端、测试协作的具体案例。
2. 独立负责核心模块、处理线上故障、推动上线的 STAR 案例。
3. 快速学习新模型/新框架并落地的过程。

## 9. 加分扩展（P2）

1. RAG 召回、重排、评测与知识库更新。
2. Kubernetes、服务网格、OpenTelemetry。
3. 多模态、语音打断（barge-in）、VAD、音频流与实时 Agent。
4. Agent Harness、MCP、A2A 等 Agent 协作模式。
