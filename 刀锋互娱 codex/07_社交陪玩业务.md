# 07｜社交陪玩 AI 业务理解

## 业务目标与技术取舍

陪玩/陪伴 Agent 的体验核心包括首响快、角色一致、有记忆、能自然打断和安全可信；商业目标可能包括留存、时长、付费转化。技术方案应按指标取舍：低延迟优先首 Token 和流式；角色一致优先记忆质量和 Prompt 版本；成本优先上下文预算和模型路由。

## 付费与权益

扣费是强副作用，不能依赖模型调用结果的“感觉”。先校验权益/余额，再用订单号或幂等键创建账务流水；状态机区分预扣、确认、取消/补偿。模型或消息失败要有清晰的退款/重试策略，并保证重复回调不会重复扣费。

## 内容安全与隐私

需要明确年龄门槛、未成年人保护、违规/自伤/诈骗等高风险策略，以及诱导消费的限制。技术上使用输入检测、系统边界、工具权限、输出审核和人工兜底的多层机制。用户聊天、画像、记忆均遵循最小化收集、传输和存储加密、访问审计、保留期限与删除能力；不要把敏感原文无差别写进日志或训练集。

## 可在面试中提出的产品问题

“当前最优先的体验指标是首响、角色一致性、留存还是付费转化？”这个问题能帮助判断后端优化重点，也体现你将工程选择和业务结果连接起来。
