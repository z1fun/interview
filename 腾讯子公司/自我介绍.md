# 14 自我介绍与面试全流程准备

## 14.1 自我介绍（1 分钟版 · 开场用）

> 面试官您好，我叫 XXX，软件工程本科毕业，有 5 年后端和全栈开发经验，主力语言是 Go。
>
> 我做过几类项目：一是 **IM 会话类系统**，在数字人项目里负责对话流程、分层记忆、消息幂等和实时语音，用到了 WebSocket 和腾讯 IM；二是 **数据与微服务系统**，用 go-zero + RabbitMQ + ETCD 搭建过多条 POS 产品线的数据中台；三是 **AI 工程化应用**，用 LangGraph 搭过多 Agent 工作流，做过 RAG 知识库，把人工审批接进自动化流程。
>
> 前端方面我用 Vue 3 独立交付过桌面应用模块。另外我日常重度使用 AI 编程工具提效，也做过不少 Prompt 工程和 Agent 开发。
>
> 我看到这个岗位做的是客户服务系统、偏 OA 方向，我做的审批流、IM 会话和权限模块和这些业务的技术内核是相通的，所以投了这个岗位，希望能有机会加入。谢谢。

**设计说明**：
- 三个关键词植入：IM 会话（对应客服系统）、AI 工程化（对应 AI 辅助开发要求）、微服务（对应架构设计经验）；
- 主动带出"审批流"破 OA 短板，不留给面试官追问；
- 时长约 50 秒，语速正常。

## 14.2 自我介绍（3 分钟版 · 技术一面用）

> 面试官您好，我叫 XXX，河南科技大学软件工程本科，2021 年毕业，5 年后端/全栈开发经验，主力 Go。
>
> **第一段经历**（2021.7-2023.12，胜睿科技）是我打基础的两年，做了两个 Gin + MySQL 的项目：一个是面向非洲市场的刷机平台，我参与了多级客户数据结构设计和返点结算；另一个是 Wi-Fi 广告系统，做了 Portal 认证页前后端。这段经历让我掌握了 Go Web 开发基本功和业务建模。
>
> **第二段经历**（2023.12-2025.4，思迅软件）我做了两个项目：一是商云前台桌面收银系统，基于 Wails + Vue 3，我负责自助模式后台、权限控制、串口外设集成等模块，是全栈交付；二是 POS 数据贯通中台，go-zero 微服务 + RabbitMQ + ETCD + gRPC，我负责销售流水、电子发票等接口和多产品线适配，这段让我把微服务、消息队列、数据治理完整实践了一遍。
>
> **第三段经历**（2025.8-2026.6，诚迈软件）我转向 AI 工程化，做了两个项目：一是用 LangGraph 搭建的漏洞研判多 Agent 工作流，里面设计了人工审批节点，用飞书卡片让专家审批，这个审批流的设计模式和 OA 审批流是一致的；二是数字人陪伴系统，我负责对话流程编排、分层记忆系统和 IM 消息幂等、实时语音计费，这套 IM 会话 + 状态管理的经验和客服系统是同一类问题。
>
> **为什么适合这个岗位**：第一，客服/OA 系统的核心技术——审批流、组织权限、IM 会话、消息可靠性——我都有对应实战；第二，岗位要求的全栈能力我有，Vue 独立交付过模块；第三，岗位要求熟练 AI 辅助开发，这是我的强项，我不仅用 AI 工具提效，还真正做过 Agent 和 RAG 的工程化落地。
>
> 以上就是我的基本情况，谢谢。

## 14.3 面试前 Checklist

### 材料与设备
- [ ] 简历电子版 + 纸质版 2-3 份（纸质与电子保持一致）
- [ ] 身份证/学历证明（子公司入职流程可能提前要）
- [ ] 电脑（代码面备用：配好 Go 环境、一个熟悉的编辑器）
- [ ] 耳机 + 麦克风（远程面试测好音视频）
- [ ] 网络备份（手机热点）

### 环境
- [ ] 远程面试：安静房间、干净背景、光线正面
- [ ] 提前 15 分钟进会议/到现场

### 内容
- [ ] 1 分钟 + 3 分钟自我介绍各演练 3 遍（录音自查）
- [ ] 每个项目的 2 分钟版本演练一遍
- [ ] 高频八股速览（模块 13 的"考前 1 小时速览"清单）
- [ ] 反问问题准备 3 个（14.4 节）
- [ ] 准备纸笔（现场画架构图用）

### 面试当天
- [ ] 着装：远程上衣整洁即可，现场商务休闲
- [ ] 回答用"结论先行 + 细节展开"结构
- [ ] 被问到不会的：坦诚 + 讲思考路径（"这个我没深入过，我的思路是……"）
- [ ] 记录被问的问题（供复盘）
