# 补充准备

> 其他必要的面试准备材料：公司背调、常见陷阱规避、技术广度速查、面试模拟题。

## 1. 公司/岗位背景调查

### 面试前必做
- [ ] 查该腾讯子公司的具体名称与业务（招聘信息中确认：是腾讯云智、腾娱互动、或其他子公司）
- [ ] 查公司近期新闻、业务方向（官方公众号、官网）
- [ ] 了解腾讯系内部系统的常用技术栈（TAPD、企业微信生态、蓝鲸平台等概念知道即可）
- [ ] 确认面试形式（现场/远程）、轮次安排

### 可了解的概念（说得出是什么即可，不必精通）
| 概念 | 一句话 |
|---|---|
| 腾讯企业微信/腾讯文档生态 | 内部 OA 常与企业微信集成（审批卡片、消息通知），你对接过飞书审批卡片，可直接类比 |
| 蓝鲸（BlueKing） | 腾讯开源的运维平台体系 |
| 北极星（Polaris） | 腾讯开源的服务治理框架（类似 go-zero 的服务发现/治理） |
| TAPD | 腾讯敏捷研发协作平台 |
| 智研 | 腾讯研发效能平台 |

## 2. 常见陷阱规避

### 简历一致性问题
- [ ] 简历上每个技术点都能讲 3 层（是什么 → 原理 → 实战）
- [ ] 简历上的"熟悉/掌握/了解"分级与实际能力一致（"熟悉"至少能讲原理）
- [ ] 项目时间线与实际一致（面试官可能追问时间重叠问题）
- [ ] LoveSpouse 项目：准备好"成人行业"的得体话术（强调技术本身，行业信息如实但不主动展开）

### 回答方式陷阱
| 陷阱 | 正确做法 |
|---|---|
| 背八股痕迹重 | 每个知识点补一句"我在 XX 项目里怎么用的" |
| 不懂装懂 | "这个我不太深入，我的理解是……，回去我再查一下" |
| 答非所问 | 先复述确认问题："您问的是 XX 场景下的 YY 对吧？" |
| 讲项目流水账 | 用 STAR 结构，突出"我"的决策和难点 |
| 贬低前司/前同事 | 只讲客观原因（业务调整、技术方向），讲"我学到了什么" |
| 过度谦虚或夸大 | 用事实和量化数据说话 |

### 敏感问题应对
- **薪资**：技术面不问不主动提；HR 面谈期望时给区间（基于当前薪资上浮 20-30% 的区间）
- **外包经历（诚迈是外包公司）**：主动讲清"项目制外包，服务华为/客户项目"，强调技术成长不因公司性质打折；这次找正式编制岗位的动机："想有稳定团队和长期业务沉淀"
- **"你之前做的都是 C 端/工具类，为什么做内部系统？"**：用 01 模块 1.4 的话术

## 3. 技术广度速查（面试前 3 天过一遍）

| 领域 | 快速自检 |
|---|---|
| Go | goroutine 泄漏怎么排查？pprof 怎么用？ |
| 网络 | 从浏览器输入 URL 到页面展示的全过程（经典题，能讲 3 分钟） |
| MySQL | 一条 update 语句的执行流程（连接器→分析器→优化器→执行器→引擎） |
| Redis | 一个 key 的过期删除策略（惰性删除+定期删除） |
| MQ | 消息堆积了怎么办？ |
| 微服务 | 服务之间调用超时怎么处理？ |
| 前端 | Vue 组件间通信方式有哪些？ |
| Linux | 查看端口占用、查看磁盘、查看内存各用什么命令？ |
| Docker | 镜像和容器的区别？Dockerfile 常用指令？ |
| AI | RAG 的完整流程？ |

## 4. 模拟面试题（考前自测）

### 模拟题 1：架构设计（15 分钟口述）
> "设计一个企业 OA 系统的请假审批功能，从员工提交到最终审批通过，请描述你的设计。"
> 参考维度：表单（动态字段+校验）→ 流程定义（多级审批、条件分支）→ 流转状态机（待审/通过/驳回/撤回）→ 通知（企业微信/邮件）→ 权限（谁能看到谁的请假）→ 扩展（会签、代理审批）。

### 模拟题 2：线上问题（10 分钟口述）
> "凌晨 2 点收到告警：客服系统 API 响应时间从 50ms 涨到 3s，你怎么处理？"
> 参考套路：确认告警真实性 → 查看监控大盘（CPU/内存/QPS/DB 连接/慢查询）→ 假设验证（流量突增？慢 SQL？下游依赖？MQ 积压？）→ 止血 → 定位根因 → 复盘。

### 模拟题 3：算法（手写，Go）
> "实现一个 LRU 缓存，要求 Get/Put O(1)。"
> 参考：map + 双向链表；注意并发安全（面试官可能追问加锁或分段锁）。

### 模拟题 4：项目追问（口头自测）
> 针对数字人项目连续追问："记忆系统四层为什么这么分？摘要和事实的存储结构？token 超限怎么办？如果摘要生成失败对话还能继续吗？"
> 检查自己能否连续答到第 4 层。

## 5. 面试时间线建议

| 时间 | 动作 |
|---|---|
| 面试前 1 周 | 通读全部模块文档，标记薄弱项 |
| 面试前 3 天 | 薄弱项专项补强；项目 STAR 演练（录音） |
| 面试前 1 天 | 13.5 速览清单 + 自我介绍演练 + 反问准备；早睡 |
| 面试当天 | 提前 15 分钟准备环境；纸笔在手边 |
| 面试后当天 | 复盘记录（14.4 节）+ 感谢信 |
| 等待期 | 1 周无消息主动询问；同时继续投递备选 |
