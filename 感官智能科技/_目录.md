## 一、这场面试的核心判断

**这家公司要什么**：能独立把 AI 情感交互服务端搭起来、能配合 App 和硬件联调、**能自己把服务部署上线**的 Go 后端。天使轮 20-99 人，不要架构师，要能干活的人。

**你的三个筹码**：
1. **LoveSpouse 与他们的产品几乎是同款** —— AI 情感陪伴 + 虚拟角色 + 配套智能硬件 App。这不是"相关经验"，是同赛道同形态的直接经验。**这是全场最强的一张牌。**
2. **AI 接入的实战深度** —— 大模型流式、分层记忆、实时语音、多 Agent 工作流。
3. **AI 编程工具重度使用者** —— 正对岗位职责第 5 条"研发提效"。

**你的两个缺口**：
- **蓝牙 GATT**（岗位职责第 3 条）—— 按「了解级」处理，用串口外设经验做迁移话术
- **运维部署**（优先条件）—— 按「三层包装法」处理，见 02 篇

**简历三处水分的处理原则**（详见 03 篇）：

| 领域 | 处理方式 |
| --- | --- |
| 微服务 | 用过 go-zero 就是微服务框架。真实表述是「用 go-zero 写过服务，了解其 RPC/服务治理能力」，**绝不说"主导过拆分"** |
| 运维 | 用过 Docker、自己部署维护服务。这在 20-99 人公司**正是他们想要的画像**，不需要伪装成大厂 SRE |
| 链路追踪 | 用「日志 traceid 串联，是链路追踪的手工版」+ 讲清 OpenTelemetry 原理 |

> **总原则**：能力边界可以承认，技术理解必须到位。面试官能接受「没做过但懂」，不能接受「说做过但答不出」。
