# CLAUDE.md

## 项目概述

本项目是**张一帆**的 **AI全栈工程师（Python+Go）面试准备材料**。基于个人简历与目标岗位招聘信息，系统化生成了面试所需的学习资料、问答预案和自我介绍。

- **候选人**：张一帆，5年经验，Go精通 + Python中游，有 LangGraph+RAG 生产级项目经验
- **目标岗位**：AI全栈工程师（python+go语言），要求 TypeScript/Vue3、RAG全栈、Agent开发、独立产品交付
- **面试时间**：2026年8月（材料标注"明天面试"）

## 关键写作约束

- 所有项目叙事素材必须来自简历.md，**禁止编造**不存在的数据或指标
- 量化用"效率提升数倍""人工介入率下降"等可辩护表述
- 面试问答答案全部**口述化**，能直接说出口，不是笔记式提纲
- 每个技术文件结尾含三件套：高频面试题 + 项目结合点 + 自查清单

## 常用任务指引

- **新增学习主题**：先在 学习框架.md 导航表加行，再创建新md，遵循统一的文件头模板
- **补充面试问答**：在 面试问答.md 对应分区末尾追加，保持「问题→要点→口述答案」格式
- **更新简历内容**：修改 简历.md 后，需同步检查 独立产品交付.md 中的叙事是否受影响
- **查看全部材料**：从 学习/学习框架.md 进入，通过导航表跳转到各文件
