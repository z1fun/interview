## 三、技术深度版（约500字，2.5分钟，面试官明显是技术背景时使用）

---

面试官你好，我叫张一帆，5年全栈开发，Go是主力语言，近两年转型AI应用方向。

我最能代表我 AI 能力的是 **AI漏洞研判系统**。这个项目的背景是SRC运营中白帽子漏洞报告处理效率低、人工审核成本高。我主导了整个技术方案设计：用 LangGraph 的 StateGraph 编排了 5 个 Agent 节点——信息完整性评估、POC构造与风险评估、POC自动验证、漏洞定级定价、自动复测——节点间通过共享状态传递，关键节点设置了条件边和人工审批中断点，通过 LangGraph 的 checkpointer 做状态持久化。

RAG 部分，我基于漏洞修复的历史记录构建了专家经验知识库，用 pgvector 做向量存储和 ANN 检索，在检索召回后加了规则过滤层做精排。飞书审批用了卡片消息交互，支持审批通过/驳回/转交。

这个系统让我把 LangGraph 编排、RAG 检索链路、工具调用、人工介入这几个 Agent 开发的核心环节都走了一遍，不是 demo 是生产环境在用的。

另外我在思迅做过一个 Dify 搭建的 AI 零售助理，用 DeepSeek 模型做了智能定价和爆款商品雷达两个工作流，通过对话式 UI 交付给商户使用，做了最小化验证。

我的后端基础是 Go——GMP并发模型、channel、context这些底层原理都比较熟，做过 go-zero 微服务中台和 Wails + Vue3 + TypeScript 桌面应用。Python 主要用在 AI 链路上：FastAPI + LangGraph + Pydantic。

这个岗位要求的全栈能力、RAG、Agent开发、Go语言，基本就是我日常在做的事情，我觉得匹配度很高。

## 五、演练提示

### 语速控制
- 标准版450字 ÷ 120秒 ≈ **每分钟225字**（正常语速150-180字/分，但这个版本信息密度高，可以稍快）
- **关键停顿点**：
  - "AI漏洞研判系统"后停顿半秒（让面试官消化项目名称）
  - "全链路智能化处理"后停顿半秒（标志性成果）
  - "匹配度很高"后自然停顿，等面试官接话

### 肢体语言
- 说"5个Agent"时可以用手指数一下（视觉辅助记忆）
- 目光接触保持自然，不要一直低头看稿
- 结束时微微前倾，表示期待交流

### 语气要点
- "生产环境在跑"——语气加重，这是核心差异点
- "不是 demo"——自信但不傲慢
- "您看想先聊哪个方面"——自然地把主动权交还给面试官
