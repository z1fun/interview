## 三、反问面试官清单

### 技术面（面技术Leader/CTO时问）

1. "团队目前AI产品的技术栈是怎样的？主要用哪些模型和框架？"
   - 目的：了解技术环境，展示你的关注点

2. "目前RAG和Agent这块，团队遇到的最大技术挑战是什么？"
   - 目的：展示你能解决实际问题，同时也了解工作难度

3. "团队在AI工程化方面——比如模型部署、监控、成本控制——目前是怎么做的？"
   - 目的：展示你对工程化的关注（加分项）

### 业务面（面产品/业务负责人时问）

4. "公司目前的AI产品主要面向什么客户场景？核心指标是什么？"
   - 目的：了解产品阶段和商业价值

5. "这个岗位接下来3-6个月最需要落地的AI功能是什么？"
   - 目的：了解对你的期望，展示你的主动性

### HR面

6. "团队的分工方式是怎样的？AI项目通常几个人协作？"
   - 目的：了解独立负责的真实程度

7. "公司对AI方向的长期投入规划是怎样的？"
   - 目的：判断公司AI战略的决心

8. "这个岗位的晋升和成长路径是怎样的？"
   - 目的：展示你在乎长期发展

### ⚠️ 避免问的问题
- 不要问网上能搜到的基本信息（公司做什么的？）
- 不要在技术面主要问福利待遇
- 不要问"加班多吗""能准时下班吗"

## 四、薪资谈判

### 市场参考（2025-2026，AI全栈，深圳）

| 级别 | 年限 | 范围 |
|------|------|------|
| 初级 | 1-3年 | 15-25K |
| 中级 | 3-5年 | 20-35K |
| 高级 | 5-8年 | 30-50K |
| 专家 | 8年+ | 45-70K |

> 以上仅供参考，实际情况取决于公司规模、融资阶段、岗位稀缺度。

### 谈判策略

1. **先让对方出价**："我更看重岗位的成长空间和做的事情，薪资上可以根据整体package来沟通。您这边的预算范围大概是多少？"

2. **报期望值要有依据**："基于AI全栈的市场行情和我的项目经验——包括LangGraph Agent编排和RAG的实战经验——我的期望是XX左右。"

3. **确认薪资结构**：
   - 基本工资 vs 绩效比例？
   - 年终奖几个月？有保底吗？
   - 有期权/股票吗？行权条件？
   - 试用期薪资打几折？

4. **单休公司的补偿**：单休意味着工作时长比双休多约20%。如果薪资和双休公司一样，实际小时工资是倒挂的。谈判时可以考虑这个因素。

## 五、知识速查一页纸（面试前30分钟过一遍）

### LLM基础
- Token是模型处理文本的最小单位，中文字≈1-2 token
- Temperature：0确定保守→1多样创意，RAG设0.1-0.3
- Function Calling让模型输出结构化工具调用

### RAG
- 链路：文档解析→切片→Embedding→向量库→检索→(重排)→生成
- 切片512字符+10%overlap，元数据绑定（来源/时间）
- 检索优化：混合检索(向量+BM25+RRF融合) + Reranker精排
- 向量库选型：规模小用pgvector（和业务库一体），规模大用Milvus

### Agent
- Agent=自主决策 | Workflow=预定义流程 | 实战常混合
- LangChain做线性Chain | LangGraph做有分支有状态的图
- StateGraph核心：State/Node/Edge/条件边/Checkpointer/Interrupt

### TypeScript/Vue3
- interface支持声明合并，type支持联合类型
- Vue3用Proxy（能检测属性增删），Vue2用defineProperty
- ref需要.value因基本类型不能Proxy，reactive不能解构（用toRefs）

### Go
- GMP：G=协程 M=线程 P=处理器，work stealing做负载均衡
- Channel：无缓冲做同步，有缓冲做队列
- "Don't communicate by sharing memory, share memory by communicating"

### Python
- GIL让多线程CPU密集无效，用asyncio做I/O、multiprocessing做CPU
- FastAPI核心：async/await + Pydantic + 依赖注入 + 自动文档
- 装饰器是高阶函数，生成器用yield惰性计算

### 项目三句话
1. 漏洞系统：5-Agent LangGraph编排 + pgvector RAG + 飞书审批人工介入
2. AI助理：Dify快速MVP + DeepSeek + CoT Prompt调优
3. 商云前台：Wails + Go + Vue3 + TS全栈桌面应用

## 六、常见陷阱问题

### "你为什么5年经验AI只做了1年多？"
> ❌ "因为AI火钱多"
> ✅ "我前3年扎实积累工程能力（Go微服务+高并发+数据库），近两年因业务需求驱动转型AI——在思迅看到商户需要AI辅助决策，在诚迈看到安全运营需要自动化。这个转型是兴趣+业务驱动，而且我发现Go的高并发能力在AI工程化里很稀缺。"

### "你最大的缺点是什么？"
> ❌ "我太完美主义"（标准回答面试官听过100遍）
> ✅ "前端深度的确不如专业前端——Vue3+TS我会用但复杂性能优化或组件库开发还在补。我正在系统学习React和前端工程化。"（说一个真实但不致命的缺点+你在怎么改）

### "你为什么离开上家公司？"
> ❌ 抱怨前公司/前领导
> ✅ "前公司的AI方向不是核心战略，我希望能在一个更聚焦AI的环境里深耕。我在找能把AI当主营业务来做的地方。"

### "你怎么看待单休？"
> ❌ "没问题"（太敷衍）或"有点难接受"（直接挂）
> ✅ "我了解了工作时间安排，这个我能接受。我关注的是工作本身的价值和成长空间——如果做的是有意义的事情，时间的付出是值得的。"

### "你还面试了哪些公司？"
> ❌ 说具体名字
> ✅ "我主要在关注AI全栈方向的岗位，有几家在沟通中。但我更看重岗位本身的匹配度和成长空间，不只是看薪资。"

### "你有什么问题要问我们？"
> ❌ "没有"（大忌！显得不关心、没思考）
> ✅ 从反问清单里选3-4个有针对性的问题

## 九、单休公司特别提醒

JD明确写了单休和固定上下班时间，在面试前请确认：

- [ ] 单休你个人能否接受？（长期单休对生活质量影响很大）
- [ ] 9:00-12:00, 13:00-18:00的工作模式（中午只有1小时休息）你是否OK？
- [ ] 薪资是否匹配单休的代价？（单休 ≈ 多工作约20%，期望薪资应相应上浮）
- [ ] 是否有年假/调休制度？

> **这不是面试技巧问题，是你需要自己做的职业决策。** 如果觉得不合适，及时止损比入职后后悔更好。
