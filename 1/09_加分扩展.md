# 09｜加分扩展

## RAG 质量改进

检索质量不只看向量模型。建立带问题、标准依据和期望答案的测试集；比较 query rewrite、混合检索、重排、切块大小和过滤条件；分别看 Recall@K、引用正确性、最终回答质量、延迟和成本。知识更新要有版本、权限与失效机制。

## 实时语音 Agent

语音链路可拆 VAD（检测说话）、ASR、LLM、TTS；全双工时要处理用户打断（barge-in），及时停止正在生成/播放的音频。关键指标是端到端首响应、打断成功率、丢包/重连和会话成功率。语音内容同样受安全、隐私与数据留存约束。

## OpenTelemetry 与云原生

OpenTelemetry 用 trace/span 将一次请求跨服务关联，Metrics/Logs 与 trace ID 相互跳转。Kubernetes 侧至少理解 readiness/liveness、资源 requests/limits、滚动更新、HPA 与优雅终止；优雅终止要先拒绝新流量、等待在途请求或到期取消，避免长连接/消费任务被粗暴中断。

## MCP 与 Agent 协作

MCP 是让模型以统一协议连接工具和资源的方式，不等于授权模型做任何操作。工程上仍要做服务端鉴权、工具最小权限、参数验证、超时、审计和版本兼容。多 Agent 只有在任务确实可分解、角色边界明确且评估可量化时才值得引入；否则简单工作流更稳定、更便宜、更容易调试。
