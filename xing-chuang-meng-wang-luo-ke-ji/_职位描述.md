# Golang 全栈开发工程师

## 基本信息

- **薪资**：20–25K
- **工作地点**：深圳 · 南山区 · 科技园
- **经验要求**：3–5 年
- **学历要求**：本科
- **职位方向**：BI 方向
- **公司**：深圳市星创梦网络科技有限公司
- **融资阶段**：天使轮
- **公司规模**：0–20 人
- **行业**：游戏
- **招聘联系人**：卢女士 · 人事

## 岗位职责

1. 参与公司核心业务系统的后端服务设计与开发，使用 Golang 构建高并发、高可用的 API 服务；
2. 负责 Web 前端功能开发与迭代，基于 Vue 技术栈（Vue 3 / Pinia / Vite）实现产品交互；
3. 负责数据分析与可视化模块的设计开发：包括数据集管理、多维分析、报表与看板的查询服务与前端呈现；
4. 参与需求评审与技术方案设计，输出合理的数据模型、接口设计与技术文档；
5. 对已有系统进行性能优化（含大数据量查询场景的 SQL 与缓存优化）、重构与稳定性治理，跟进线上问题排查与修复；
6. 与产品、测试、运维及数据团队协作，参与代码评审（Code Review），保障工程质量与交付节奏。

## 任职要求

1. 3 年以上后端开发经验，具备扎实的 Golang 功底，熟悉常见并发模型，熟悉至少一个主流 Web 框架（Gin / Echo 等）；
2. 熟悉 PostgreSQL（索引优化、执行计划分析、慢查询排查），熟悉 Redis（缓存策略、分布式锁）；
3. 2 年以上 Vue 开发经验，熟练掌握 Vue 3 组合式 API、Pinia 状态管理与 Vite 工程化，能独立完成中复杂度前端页面；
4. 1 年以上 BI 相关开发经验：有报表、看板、多维分析类系统的设计与实现经验，能编写高效的复杂 SQL（多表关联、窗口函数、CTE）；
5. 熟悉至少一种 BI / 可视化工具或库（如 Superset、Metabase、ECharts、AntV）；
6. 熟悉 Git 工作流与团队协作规范，有 Linux 基础，掌握 Docker 容器化部署；
7. 具备良好的沟通能力与责任意识，能独立推进模块从设计到上线。

## 加分项

- 有 ClickHouse / Doris / StarRocks 等 OLAP 引擎的使用或接入经验；
- 有基于 PostgreSQL 的生态实践经验（如 TimescaleDB、PostGIS、逻辑复制 / CDC）；
- 有 Kubernetes / 云原生实践经验；
- 有 ETL / 数据管道相关经验，或参与过数据仓库建设；
- 了解 CI/CD 流水线搭建（GitHub Actions / GitLab CI）；
- 参与过从 0 到 1 的完整项目，或开源项目贡献经历。
