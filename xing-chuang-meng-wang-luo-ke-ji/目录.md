## 本次只准备这些

- **项目**：POS 数据贯通、商云前台；数字人消息幂等作为备用案例。
- **BI/SQL**：指标、粒度、JOIN 重复、窗口函数、索引、执行计划。
- **Go/Redis**：有限并发、context、泄漏、消费幂等、缓存、锁。
- **Vue**：computed/watch、Pinia、请求竞态、图表生命周期、Vite。
- **综合**：用 Go + PostgreSQL + Redis + Vue 设计一个运营看板。

暂缓 OLAP 引擎细节、CDC、数仓分层、K8s、PostGIS、TimescaleDB；本轮不搭 Demo。加分项被问到时说明理解和实际经验即可。
