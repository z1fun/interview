## 一、认知修正（读这行再往下）

**招聘信息中的 "Harness" ≠ Harness.io（CI/CD 软件交付平台）。**

正确理解：**Harness = Agent Harness（智能体驾驭层工程）**，核心公式：

```
Agent = Model（引擎）+ Harness（底盘）
```

- **Model**：只负责推理（文本进 → 文本出）
- **Harness**：包裹模型之外的一切工程设施——工具系统、执行环境、编排逻辑、记忆系统、安全护栏、CI/CD 反馈闭环

> Claude Code 被业界公认为"目前最完整的工业级 Agent Harness 实现之一"。你每天都在用 Claude Code——这是最强的第一手 Harness 实践，面试中要主动提到。

**来源**：[深入浅出Agent: Harness最全调研与原理解析 (CSDN)](https://blog.csdn.net/sjkflw121150/article/details/162765700)、[一文讲透如何构建Harness (腾讯云)](https://cloud.tencent.com.cn/developer/article/2648873)、[claude-code-book](https://github.com/lintsinghua/claude-code-book)

## 三、面试策略三大支柱

无论被问到什么，始终围绕这三个支点：

1. **Claude Code 日常深度使用** = 工业级 Agent Harness 的第一手实践（工具系统、权限、Skill、MCP、SubAgent、Hook、Plan 模式）
2. **LangGraph 5-Agent 漏洞研判系统** = Agent 编排、RAG、Prompt 调优、Human-in-Loop 完整落地
3. **Go/go-zero 5 年后端** = 高并发微服务、消息队列、分布式缓存基本功扎实
