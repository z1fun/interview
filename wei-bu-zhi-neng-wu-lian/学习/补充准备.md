## 二、面试反问问题清单

> ⚠️ 反问环节是展示思考深度的机会——问技术架构和产品，不要问"几点上班"

### 推荐问题（选 3-4 个）：

1. **框架方向**："贵司的 Harness 框架是自研的还是基于某个开源方案改造的？目前成熟度大概在什么阶段？"
   - 展示：你关心 Harness 本身，不只是把它当工具用

2. **产品规模**："目前数字人产品的用户量级大概多少？DAU/MAU 在什么范围？"
   - 展示：你关心架构需要支撑的规模，不同量级架构完全不同

3. **对话引擎**："对话引擎用的是流式返回（SSE/WebSocket）还是同步返回？有没有做多模型路由来平衡成本和效果？"
   - 展示：你对对话系统的技术选型有思考

4. **记忆系统**："记忆系统目前用的什么向量数据库？pgvector 还是 Milvus？检索策略上有没有做时间衰减或情感标注？"
   - 展示：你对记忆系统有深入理解

5. **人设管理**："人设 Prompt 的迭代管理是怎么做的？是写在配置文件里还是有专门的 Prompt 管理平台？"
   - 展示：你关心工程化能力（而不是"一个 Prompt 调到底"）

6. **团队分工**："团队目前的规模和分工是怎样的？这个岗位会更侧重 Agent 架构设计还是具体业务功能落地？"
   - 展示：你关心自己在团队中的定位

### 可选问题（如果氛围好）：

7. "数字人的'拟人度'效果怎么评估的？内部有 LLM-as-Judge 评估流程吗？"
8. "对于数字人的主动交互（定时问候/事件提醒），目前有没有做频率控制和 A/B 测试？"

## 四、行为问题速查

### 优缺点

> **优点**：学习能力强——从 Go 后端转到 AI Agent 开发，快速上手了 LangGraph、RAG、Prompt 调优，项目 5 个月从零到生产。工程落地导向——不满足于 demo，追求生产可用。
>
> **缺点**：没有 2C 数字人产品的直接经验，但我对这个赛道有强烈兴趣，目前在快速补充产品形态和用户交互方面的认知。同时我相信 Agent 工程的核心能力是相通的。

### 离职原因

> "上一家公司的 AI 安全项目进入维护期，技术挑战减少。我希望找一个 AI Native 的团队深入做 Agent 工程。数字人智能体这个方向——既有 Agent 工程的技术深度，又有 2C 产品的用户反馈——是我非常想深耕的赛道。"

### 职业规划

> "短期：深入掌握 Agent Harness 工程，在数字人核心能力（人设系统、记忆系统、对话引擎）上做出有用户体感的成果。中期：成长为能独立设计数字人 Agent 架构的工程师，可以带小团队攻坚核心模块。长期：成为 AI Agent 工程化方向的专家。"

### 遇到过最大的技术挑战

> "在漏洞研判系统中，5 个 Agent 节点的编排状态管理是一个挑战——不同漏洞类型需要不同的流转路径，而且中途可能被人工审批驳回。LangGraph 的 StateGraph 解决了这个问题——用条件边（conditional edge）实现了动态路由，用 checkpoint 实现了中断恢复。最后实现了一个灵活可配的编排引擎。"
