## 一、1 分钟版（推荐，面试开场用）

> "面试官你好，我叫张一帆，5 年后端开发经验，主力语言是 Go 和 Python。
>
> 最近一年我深度参与 AI Agent 工程落地。我主导开发了一个基于 LangGraph 的 AI 漏洞研判系统——用 5 个 AI Agent 协作，覆盖了漏洞从提交到自动审核的全链路，涉及 **Agent 编排、RAG 记忆检索、Prompt 调优和人机协同**。这个系统已经在生产环境处理真实的 SRC 漏洞。
>
> 同时我是 **Claude Code 的日常深度用户**。在长期使用中，我系统理解了 Agent Harness 的核心架构——工具系统、权限管线、Skill/MCP 插件体系、上下文管理和记忆机制。我理解 Harness 的核心公式是 'Agent = Model + Harness'——模型负责推理，Harness 负责把推理变成可靠、可治理的行动。
>
> 另外，我在 Go 微服务方向有扎实的高并发实战——用 go-zero 搭建过处理多产品线数据流的微服务系统，涉及自适应降载、熔断器、RabbitMQ 异步解耦和 Redis 多级缓存。
>
> 贵司的数字人智能体方向对我非常有吸引力——将 Agent 工程能力和 2C 用户体验结合，这正是我希望深耕的赛道。虽然我之前没有直接做过数字人产品，但我认为对话编排、记忆系统、RAG 检索和工具调用这四项核心技术栈是高度一致的，我的工程能力可以直接迁移。我也很期待在 Harness 框架的实际落地中更深入地成长。"

**时间**：约 55-60 秒

## 三、3 分钟版（深度面试，技术面用）

> （在 1 分钟版基础上，每段展开细节）

**展开 Agent 实战经验**（额外 40 秒）：

> "漏洞研判系统用了 LangGraph 的 StateGraph 状态机来编排 5 个 Agent 节点——信息完整性评估、POC 构造与风险评估、POC 自动验证执行、漏洞定级定价、自动复测。每个节点有独立的 Prompt 角色定义，类似数字人的'人设系统'。技术栈是 Python + FastAPI + PostgreSQL + pgvector，RAG 链路用了语义相似度检索加时间衰减，关键节点通过飞书审批卡片实现 Human-in-Loop。这个项目让我理解了从 Prompt 设计到生产部署的完整 Agent 工程链路。"

**展开 Claude Code Harness 理解**（额外 40 秒）：

> "通过深度使用 Claude Code，我亲历了工业级 Agent Harness 的完整设计。比如它的工具系统有 15+ 工具，权限管线是 fail-closed 默认——每次敏感操作都要确认，这对应贵司需求中的'权限治理'。Skill 系统用了渐进披露设计，不调用不占上下文——这对应'流程编排'中资源的高效利用。MCP 协议标准化了外部工具接入——这对应'自定义插件开发'。Plan/Act 分离架构让复杂任务先出方案再执行——这对应'任务体系'的状态管理。这些机制和贵司 Harness 框架的抽象层是高度一致的。"

**展开高并发**（额外 30 秒）：

> "在思迅的 POS 数据贯通项目中，我用 go-zero 搭建了微服务中台——自适应降载保护系统过载、Breaker 熔断防止下游雪崩、RabbitMQ 异步解耦保证数据一致性、Redis 缓存提升查询性能。虽然不是千万级，但百万级流量的架构思路是通用的。"

## 五、注意事项

1. **语速**：正常偏慢，1 分钟版控制在 55-60 秒（不要赶）
2. **眼神**：看摄像头（线上面试）或看面试官眼睛（线下面试）
3. **停顿**：每段之间自然停顿 1-2 秒，不要连珠炮
4. **语气**：自信但不张扬，"我做过"比"我精通"更有说服力
5. **准备被追问**：自我介绍里提到的每个技术点（LangGraph、pgvector、go-zero 降载、Skill 懒加载）都要准备好被深挖
6. **不要背诵**：把关键框架记住，具体措辞临场发挥，听起来更自然
